# Thrive- Watch every achievement become a checkmark

**Thrive** is a dynamic web application that helps users create, manage, and track their bucket list goals.

---

## Features

- **Add Goals:** Users can add new goals to their personal bucket list.  
- **Edit Goals:** Modify goal details anytime.  
- **Delete Goals:** Remove goals that are no longer relevant.  
- **Mark as Complete:** Track progress by marking goals as completed.  
- **Live Progress Bar:** Visual representation of your overall goal completion.  

---

## Technologies Used

- **Frontend:** HTML, CSS, JavaScript  
- **Backend & Database:** MongoDB  

---

## Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/thrive.git
   ```
2. **Navigate to the backend folder**
   ```bash
   cd thrive/backend
   ```
3. **Install dependencies**
   ```bash
   npm install
   ```
4. **Set up environment variables:**
- Create a .env file in the backend folder:
  ```bash
  touch .env
  ```
- Add your configuration, for example:
  ```ini
  MONGO_URI=your_mongodb_connection_string
  PORT=8080
  ```
5. **Start the application**
   ```bash
   npm start
   ```
